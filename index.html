Kết nối API · token game

Dán access token hoặc toàn bộ JSON gồm token, refreshToken và tokenHeader. Token dùng để đọc kết quả; khi bạn bật CƯỢC THẬT, trang dùng chính token này để đặt cược bằng tiền thật trên tài khoản đó.

Trang KHÔNG xin token mới từ máy chủ. Token dán vào được dùng tới khi hết hạn; khi hết thì bấm bookmarklet lấy cụm mới rồi dán lại. Đây là cách tránh hoàn toàn lỗi 401 / code 4.

🔖 Cài bookmarklet Token dùng tới khi hết hạn — lấy cụm mới bằng bookmarklet rồi dán lại.
Đường mạng gọi API — mặc định «Trực tiếp» (đúng nhất khi trang chạy trên GitHub Pages). Chỉ đổi sang proxy khi Console báo CORS hoặc ERR_FAILED.
Đã có token nhưng thiếu refreshToken? Dán riêng refreshToken vào đây — token đang chạy được giữ nguyên, không phải dán lại access token.
