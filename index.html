Token đọc kết quả

        
Token là tuỳ chọn. Bảng số tự đồng bộ từ Firebase nên máy không có token vẫn xem được.
           Chỉ cần dán token khi bạn muốn máy này tự nạp kết quả mới từ máy chủ game.

        
Dán access token (chuỗi eyJ…) hoặc cả cụm {"token":"…","refreshToken":"…","refreshHeader":"…"}.
           Token chỉ dùng để đọc kết quả, lưu trên máy bạn.
