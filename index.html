Kết nối API · token game

Dán access token hoặc toàn bộ JSON gồm token, refreshToken và tokenHeader. Token dùng để đọc kết quả; khi bạn bật CƯỢC THẬT, trang dùng chính token này để đặt cược bằng tiền thật trên tài khoản đó.

Không cần đăng xuất game nữa: nếu cụm dán vào có refreshToken, trang tự gia hạn token liền tay (còn ~10 phút là làm mới) → token không bao giờ hết. Chỉ cần lấy đủ cụm 1 lần đầu bằng nút bên dưới.

Đã có token nhưng thiếu refreshToken? Dán riêng refreshToken vào đây — token đang chạy được giữ nguyên, không phải dán lại access token.
